# 🚗 Driving Simulator

A realistic driving simulation game built with Babylon.js and Havok Physics, featuring mod support and local multiplayer.

## ✨ Features

- **Realistic Physics** - Powered by Havok Physics engine
- **Mod Support** - Import custom vehicles and maps (GLB/GLTF)
- **Auto-Detection** - Automatically detects wheels, body, and vehicle type
- **Dynamic Camera** - External and cockpit cameras that adapt to vehicle size
- **Local Multiplayer** - Play with friends on the same Wi-Fi network (up to 4 players)
- **Mobile Optimized** - Responsive controls for phones and tablets
- **Cross-Platform** - Works on web, Android, and desktop

## 🎮 Controls

### Touch (Mobile)
- **Left Side**: Steering buttons (◀ ▶)
- **Right Side**: Gas (▲) and Brake (▼)
- **Top Right**: Camera toggle (📷) and Pause (⏸)

### Keyboard
- **W/↑**: Accelerate
- **S/↓**: Brake
- **A/←**: Steer Left
- **D/→**: Steer Right
- **C**: Toggle Camera
- **P**: Pause

### Gamepad
- **Left Stick**: Steering
- **Right Trigger**: Gas
- **Left Trigger**: Brake
